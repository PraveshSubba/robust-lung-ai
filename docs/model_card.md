# RobustLungAI — Model Card

## 1. Model Overview

| Field               | Description                                 |
| ------------------- | ------------------------------------------- |
| Project             | RobustLungAI                                |
| Task                | Four-class respiratory sound classification |
| Architecture        | Audio Spectrogram Transformer (AST)         |
| Starting checkpoint | `MIT/ast-finetuned-audioset-10-10-0.4593`   |
| Framework           | PyTorch and Hugging Face Transformers       |
| Primary dataset     | ICBHI 2017 Respiratory Sound Database       |
| Application         | Gradio                                      |

RobustLungAI is a personal MSc research project investigating AST-based respiratory sound classification and robustness under different recording conditions.

The deployed application should use the fine-tuned checkpoint specified in its source code and hosted in the [RobustLungAI Hugging Face repository](https://huggingface.co/praveshsubba/robustlungai-ast).

## 2. Intended Use

The model is intended for:

* Research and educational experiments.
* Respiratory audio classification demonstrations.
* Evaluation of training objectives and data augmentation.
* Investigation of noise and recording-device robustness.
* Exploration of model interpretability techniques.

The model is not intended to diagnose disease, recommend treatment, make patient-triage decisions, or replace professional medical assessment.

## 3. Input and Preprocessing

The documented AST configuration includes:

* Sampling rate: 16,000 Hz.
* Target respiratory-cycle duration: 8 seconds.
* Mel representation: 128 Mel bins.
* Feature extraction: Hugging Face AST feature extractor.

The precise filtering, segmentation, normalization, padding, and truncation settings must match the deployed checkpoint and the corresponding experiment.

For the application, consult `app/gradio_app.py`. For research experiments, consult the relevant notebook in `notebooks/`.

## 4. Output Classes

| Class     | Annotation meaning                     |
| --------- | -------------------------------------- |
| `normal`  | Neither crackles nor wheezes annotated |
| `crackle` | Crackles annotated                     |
| `wheeze`  | Wheezes annotated                      |
| `both`    | Both crackles and wheezes annotated    |

These classes reflect the annotation scheme used by the project. They are not comprehensive clinical diagnoses.

The application may display scores or probabilities generated by the model. These outputs have not been established as calibrated clinical probabilities.

## 5. Training and Evaluation

The research investigates:

* Random Forest with MFCC features.
* A simple CNN baseline.
* AST fine-tuning with cross-entropy.
* AST fine-tuning with focal loss.
* Focal loss with supervised contrastive learning.
* SpecAugment and Mixup.
* Recording-device generalization.
* Added-noise robustness.
* Cross-dataset transfer.
* Noise-augmented training.
* Attention rollout and Grad-CAM visualizations.

The internal experiments use a patient-level 70/15/15 training, validation, and test split. This is distinct from the official ICBHI challenge split.

The documented internal results must not be interpreted as official challenge results or independent clinical validation.

## 6. Data

The primary dataset is the ICBHI 2017 Respiratory Sound Database.

Additional cross-dataset evaluation uses a selected SPRSound subset containing 355 WAV recordings and 355 corresponding JSON annotation files.

SPRSound and ICBHI differ in their collection populations, recording conditions, and annotation schemes. Cross-dataset evaluation therefore depends on the selected subset, label mapping, and preprocessing.

Refer to the original dataset sources:

* [ICBHI 2017 Challenge](https://bhichallenge.med.auth.gr/ICBHI_2017_Challenge)
* [SPRSound repository](https://github.com/SJTU-YONGFU-RESEARCH-GRP/SPRSound)
* [SPRSound paper](https://doi.org/10.1109/TBCAS.2022.3204910)

## 7. Performance Reporting

The project reports sensitivity, specificity, ICBHI score, and other classification metrics where available.

The binary ICBHI score groups crackle, wheeze, and both as abnormal:

**ICBHI score = (abnormal sensitivity + normal specificity) / 2**

Results depend on the evaluation split and experimental configuration. Consult the README, consolidated results CSV, and original experiment notebooks for recorded metrics.

## 8. Limitations and Risks

* Performance may vary with population, recording device, environment, audio quality, and dataset.
* Noise and device robustness experiments cover only the tested conditions.
* Cross-dataset performance does not establish generalization to all patient populations.
* Annotation errors and differences in class definitions may affect predictions.
* Model scores are not necessarily calibrated probabilities of disease.
* Attention and Grad-CAM visualizations do not establish causality or clinical validity.
* The model has not been established as suitable for clinical use.

## 9. Responsible Use

Use RobustLungAI for research and educational purposes only.

Do not use its predictions as the sole basis for clinical decisions. Any future clinical application would require appropriate independent validation, evaluation across relevant populations and recording conditions, and applicable regulatory review.
