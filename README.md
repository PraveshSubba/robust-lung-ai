# RobustLungAI

**Robust Respiratory Sound Classification under Noise and Domain Shift using Audio Spectrogram Transformers**

RobustLungAI is a personal MSc research project exploring respiratory sound classification using Audio Spectrogram Transformers (AST). The project investigates four-class classification, training objectives, data augmentation, recording-condition robustness, cross-dataset evaluation, and model interpretability.

> **Research and educational use only.** RobustLungAI is not a clinically validated diagnostic system and must not be used as the sole basis for medical decisions.

## Project at a Glance

* **Task:** Four-class respiratory sound classification
* **Classes:** Normal, crackle, wheeze, and both
* **Architecture:** Audio Spectrogram Transformer (AST)
* **Framework:** PyTorch and Hugging Face Transformers
* **Primary dataset:** ICBHI 2017 Respiratory Sound Database
* **Additional evaluation:** Selected SPRSound subset
* **Application:** Gradio
* **Model weights:** [Hugging Face repository](https://huggingface.co/praveshsubba/robustlungai-ast)

## Model

The project uses the pretrained AST checkpoint:

`MIT/ast-finetuned-audioset-10-10-0.4593`

The documented preprocessing configuration includes a 16 kHz sampling rate, 8-second target cycles, and 128 Mel bins. The exact configuration must match the experiment and checkpoint being evaluated.

The fine-tuned model is hosted separately on Hugging Face:

[View RobustLungAI model files](https://huggingface.co/praveshsubba/robustlungai-ast)

Refer to the model repository and application code for the checkpoint filename and loading instructions.

## Research Objectives

1. Establish traditional machine-learning and CNN baselines.
2. Fine-tune AST using cross-entropy and focal loss.
3. Investigate supervised contrastive learning.
4. Compare SpecAugment and Mixup configurations.
5. Evaluate robustness to added noise and recording-device differences.
6. Investigate cross-dataset transfer using a selected SPRSound subset.
7. Explore attention rollout and Grad-CAM visualizations.

## Experimental Results

The following results were recorded using the internal patient-level 70/15/15 split. Scores are percentages. This is not the official ICBHI challenge evaluation protocol.

### Baseline and loss-function experiments

| Model                | Split      | Sensitivity | Specificity | ICBHI score |
| -------------------- | ---------- | ----------: | ----------: | ----------: |
| Random Forest + MFCC | Validation |       23.83 |       81.45 |       52.64 |
| Simple CNN           | Validation |       78.94 |       28.51 |       53.72 |
| Random Forest + MFCC | Test       |       18.79 |       91.45 |      55.05* |
| Simple CNN           | Test       |       74.58 |       41.89 |       58.23 |
| AST + Cross-Entropy  | Validation |       67.45 |       74.51 |       70.98 |
| AST + Cross-Entropy  | Test       |       56.51 |       76.87 |       66.69 |
| AST + Focal Loss     | Validation |       61.49 |       79.49 |       70.49 |
| AST + Focal Loss     | Test       |       48.32 |       83.22 |       65.77 |
| AST + Focal + SupCon | Validation |       66.81 |       71.49 |       69.15 |
| AST + Focal + SupCon | Test       |       43.49 |       88.86 |       66.17 |

### Augmentation ablation

| Configuration       | Split      | Sensitivity | Specificity | ICBHI score |
| ------------------- | ---------- | ----------: | ----------: | ----------: |
| Baseline            | Validation |       54.68 |       85.97 |       70.33 |
| Baseline            | Test       |       48.53 |       79.69 |       64.11 |
| SpecAugment         | Validation |       80.21 |       62.29 |       71.25 |
| SpecAugment         | Test       |       61.55 |       66.71 |       64.13 |
| Mixup               | Validation |       66.38 |       75.11 |       70.75 |
| Mixup               | Test       |       50.42 |       81.66 |       66.04 |
| SpecAugment + Mixup | Validation |       74.47 |       63.95 |       69.21 |
| SpecAugment + Mixup | Test       |       66.66 |       67.84 |       67.22 |

**Metric verification:** The Random Forest test sensitivity and specificity average to approximately 55.12%, not the recorded 55.05%. This discrepancy remains unresolved and should be checked against the original experiment output.

The loss-function and augmentation experiments are separate experiment groups. Interpret their results in the context of their individual configurations and evaluation procedures.

The consolidated results file is [`results/tables/results_phase3_combined.csv`](results/tables/results_phase3_combined.csv).

## Robustness and Cross-Dataset Evaluation

The project contains experiments for:

* Cross-device generalization.
* Added-noise robustness at different signal-to-noise ratios.
* Cross-dataset transfer using a selected SPRSound subset.
* Noise-augmented training as a possible robustness mitigation.

The selected SPRSound subset contains 355 WAV recordings and 355 corresponding JSON annotation files. Cross-dataset results depend on the evaluated subset, annotation mapping, and preprocessing; they do not establish general clinical validity.

Dataset: [SPRSound official repository](https://github.com/SJTU-YONGFU-RESEARCH-GRP/SPRSound)

Publication: Zhang et al., *SPRSound: Open-Source SJTU Paediatric Respiratory Sound Database*, 2022. [DOI](https://doi.org/10.1109/TBCAS.2022.3204910)

## Interpretability

Notebook `05a-interpretability.ipynb` investigates attention rollout and Grad-CAM visualizations associated with model predictions.

These visualizations are exploratory. They do not prove causal reasoning, identify disease with clinical certainty, or independently validate the model.

## Reproducing Experiments

The experiments were developed primarily in Kaggle notebooks. Reproduction may require the original datasets, prepared manifests, waveform caches, checkpoints, compatible dependencies, and experiment-specific configuration.

Start with the data-preparation notebook and follow the notebook for the experiment of interest. The final-results notebook aggregates recorded experiment outputs; it does not retrain all models.

Dataset files, waveform caches, and large model checkpoints are not included in the repository by default.

See [`docs/reproducibility.md`](docs/reproducibility.md) for details.

## Limitations and Responsible Use

* Results depend on dataset splits, annotations, preprocessing, and training configuration.
* The internal patient-level split is not the official ICBHI challenge split.
* Robustness findings apply only to the conditions actually evaluated.
* Model outputs should not be interpreted as calibrated clinical probabilities without appropriate validation.
* Interpretability visualizations are not proof of causal explanations.
* This project is intended for research and education, not standalone clinical diagnosis.
